# SAP status glossary (synthetic summary for the assistant)

- OverallSDProcessStatus: A = not yet processed, B = partially processed, C = completely processed.
- OverallDeliveryStatus: A = not delivered, B = partially delivered, C = fully delivered.
- Billing status: A = not billed, B = partially billed, C = fully billed.
- Credit check status: A = check passed, B = check failed (order blocked), D = released by credit team.
Only the AR credit team can release a credit block.
